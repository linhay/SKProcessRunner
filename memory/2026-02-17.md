# 2026-02-17

## SKProcessRunner Issue #3
- 决策：新增 `SKProcessPipeSession`（非 PTY、Pipe 语义）以承载 JSON-RPC over stdio 长连接通信。
- 关键实现：
  - 双流输出：`stdout` / `stderr` 均为 `AsyncStream<Data>`。
  - 双向交互：`send(_:)` + `closeStdin()` + `wait()`。
  - 生命周期：支持 `terminate()` 与 `pid` 暴露。
  - 超时处理：复用进程树终止策略，保证可回收性。
  - 错误模型：新增 `SKProcessRunError.pipeFailed(String)`。
- 验证：
  - 新增 `SKProcessPipeSessionTests`，覆盖 1000 行往返、stdout/stderr 分离、timeout、nonZeroExit。
  - `swift test --filter SKProcessPipeSessionTests` 通过。
- 文档：
  - `docs-dev/features/issue-3-non-pty-pipe-session.md`
  - `docs-dev/dev/issue-3-pipe-session-design.md`
  - README 新增 `SKProcessPipeSession` 使用说明。

## SKProcessRunner Issue #3 Follow-up（Nolon 集成崩溃）
- 反馈：Nolon 集成 `SKProcessPipeSession` 后在 Swift Testing 环境出现 `EXC_BAD_ACCESS / SIGBUS`（`swiftpm-testing-helper`）。
- 处理决策：对 Pipe 会话的 IO 生命周期做并发收敛，避免关闭阶段与读取阶段并发竞争。
- 关键改动：
  - `SKProcessPipeSession` 从 `FileHandle.readabilityHandler` 切换为 `DispatchSourceRead`。
  - 在会话结束路径先 `cancel` read source，再统一 drain 输出并 finish stream。
  - 新增压力测试 `testPipeSessionLifecycleStressDoesNotCrash`（100 轮创建/等待）用于回归。
- 验证：
  - `swift test --filter SKProcessPipeSessionTests` 通过（5/5）。

## SKProcessRunner iOS 兼容策略收敛
- 反馈：iOS 构建链路报错 `Cannot find type 'Process' in scope`（定位到 `SKProcessPipeSession`）。
- 决策：`SKProcessPipeSession` 仅在 macOS 提供，iOS 编译期不可用。
- 关键改动：
  - `SKProcessPipeSession` 增加条件编译：`#if os(macOS)` 提供完整实现，`#else` 提供 iOS 不可用占位声明。
  - README / docs-dev 明确平台支持矩阵与不可用语义。
- 风险结论：
  - 避免 iOS 运行时失败，改为编译期显式失败，调用方更可控。

## 工具链环境问题修复（iOS 构建）
- 反馈：在 iOS 目标编译中报 `Cannot find type 'Process' in scope`，并伴随 `posix_spawn_file_actions_addchdir*` 可用性错误。
- 关键修复：
  - `RunAsync` / `RunSync` 增加非 macOS fallback（抛 `unsupportedPlatform`），避免 iOS 编译解析 `Process` 实现体。
  - `SKProcessTreeTerminator` 增加非 macOS fallback 实现，去除 iOS 构建期对 `Process` 的依赖。
  - `SKProcessPTYSupport` 在 macOS 使用 `addchdir`/`addchdir_np` 条件分支，iOS 跳过该 file action。
- 验证：
  - `swift test --filter SKProcessPipeSessionTests` 通过（5/5）。
  - `swift build --sdk $(xcrun --sdk iphonesimulator --show-sdk-path) --triple arm64-apple-ios14.0-simulator` 通过。
