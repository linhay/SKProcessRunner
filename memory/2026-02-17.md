# 2026-02-17

## SKProcessRunner Issue #3
- 决策：新增 `SKProcessPipeSession`（非 PTY、Pipe 语义）以承载 JSON-RPC over stdio 长连接通信。
- 关键实现：
  - 双流输出：`stdout` / `stderr` 均为 `AsyncStream<Data>`。
  - 双向交互：`send(_:)` + `closeStdin()` + `wait()`。
  - 生命周期：支持 `terminate()` 与 `pid` 暴露。
  - 超时处理：复用进程树终止策略，保证可回收性。
  - 错误模型：新增 `SKProcessRunError.pipeFailed(String)`。
- 验证：
  - 新增 `SKProcessPipeSessionTests`，覆盖 1000 行往返、stdout/stderr 分离、timeout、nonZeroExit。
  - `swift test --filter SKProcessPipeSessionTests` 通过。
- 文档：
  - `docs-dev/features/issue-3-non-pty-pipe-session.md`
  - `docs-dev/dev/issue-3-pipe-session-design.md`
  - README 新增 `SKProcessPipeSession` 使用说明。
